# Dependencias

## Aplicacion

| Dependencia | Funcion |
| --- | --- |
| `react` | Construccion de la interfaz mediante componentes. |
| `react-dom` | Renderizado de React en el navegador. |
| `react-router-dom` | Navegacion y manejo de rutas de la aplicacion. |

## Desarrollo

| Dependencia | Funcion |
| --- | --- |
| `typescript` | Tipado estatico para JavaScript. |
| `vite` | Servidor de desarrollo y empaquetado. |
| `@vitejs/plugin-react` | Integracion de React con Vite. |
| `eslint` | Analisis estatico para mantener calidad de codigo. |
| `typescript-eslint` | Reglas de ESLint para TypeScript. |
| `@eslint/js` | Configuracion base de reglas de ESLint. |
| `eslint-plugin-react-hooks` | Validacion de las reglas de Hooks de React. |
| `eslint-plugin-react-refresh` | Soporte de reglas para React Fast Refresh. |
| `globals` | Definiciones de variables globales para ESLint. |
| `@types/node` | Tipos de TypeScript para Node.js. |
| `@types/react` | Tipos de TypeScript para React. |
| `@types/react-dom` | Tipos de TypeScript para React DOM. |
